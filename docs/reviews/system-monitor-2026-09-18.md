# 悬浮面板系统监控评审与调整

日期：2026-09-18。基于当前工作区实现、原版应用的设置界面，以及使用生产视图代码的隔离 UI 验证程序。

## 发现与处理

| 问题 | 原因与影响 | 本次处理 |
| --- | --- | --- |
| 无法单独调整内存高度 | 高度由行数 × 密度 × 颗粒尺寸共同决定；为增加高度而放大颗粒会同时改变所有图表 | 内存图表区域独立设置 24–200 pt；标题、说明在区域之外自然排布 |
| 同一个尺寸设置牵动多处布局 | CPU/GPU 固定 8 行，网络/磁盘每条固定 4 行；密度实际改变高度，不是可预测的精细度 | CPU/GPU 走势 24–160 pt；网络/磁盘双走势总高 32–120 pt；颗粒大小与高度解耦，移除重复的密度控件 |
| 项目只能成组开关 | CPU/GPU、网络/磁盘强制绑定 | 五个项目独立显示；单项自动铺满宽度；全关时提供提示 |
| 内存图表可能重复累计 | 系统内存由活跃、不可分页和压缩页估算，GPU 来自另一接口，不能认为是可直接相加的独立类别 | 仅用系统已用量绘制占用率，GPU 内存单独作为参考值，不再堆叠 |
| 占用率被当作压力着色 | `collectMemory()` 的 pressure 实际是 used / total，并非操作系统内存压力 | 改为稳定的内存类别色，说明这是估算占用量；本次不新增真正的内存压力采集 |
| 网络/磁盘历史不在同一刻度 | 每个新样本按当时的衰减峰值归一化，旧样本仍保留旧比例 | 保存原始速率，用整个历史窗口的共同峰值缩放两条曲线，显示满刻度和 KB/s、MB/s |
| 改颗粒大小会改变可见历史窗口 | 旧图表按能容纳的列数截取 suffix | 保留最近 60 次采样；列数不足时按区间取峰值，保留短暂尖峰。采样频率可变，因此不宣称固定 60 秒 |
| 预览比真实内容宽 | 原预览直接给模块 400 pt，实际面板还扣除容器边距 | 预览使用 400 pt 外宽和与实际一致的 12 pt 容器边距 |
| GPU 方块容易误读成逐核心负载 | 实际只根据 GPU 总体利用率点亮方块 | 明确标记总体负载，并用提示说明不代表独立核心 |
| 细小文字、单位和控制名称含糊 | 8–9 pt 图例，K/M 无速率单位，“走势向”“行列开阵列”等难理解 | 主要明细提升至 10 pt；速率分行显示；改用“同向向上 / 上下镜像”等直接表述 |
| 大尺寸配置可能使整个面板超出屏幕 | 根容器自然增高，无滚动上限 | 根面板根据已连接屏幕的最小可用高度限高，超出后滚动，并响应显示器配置变化 |
| 空历史和网格边界不稳健 | 空数组仍访问第 0 项，列数向上取整可能超出宽度 | 空数据补零；非有限值清理；网格精确计算分组间隔，保证适配边界 |

## 新的自定义方式

- 内存布局：走势与占用矩阵、仅走势、仅占用矩阵。
- 内存、CPU/GPU、网络/磁盘三组独立高度；滑块配步进按钮，可精确微调。
- CPU、GPU、内存、网络、磁盘五项独立显隐。
- CPU/GPU 负载方块、CPU 温度、明细与刻度说明可隐藏。
- 区域间距 4–24 pt。
- 保留圆角方块、方块、圆点；走势颗粒 2–10 pt、负载方块 4–20 pt、图表颗粒间距 0–4 pt、每四格行/列分隔。
- 即时保存、同宽预览、恢复本模块默认值。隐藏项目对应的尺寸控制自动禁用。
- 一次性迁移旧显隐和自定义密度产生的高度；不会每次启动覆盖新设置。恢复默认只影响系统监控。

## 仍需区别对待的限制

1. GPU 指标不可读取时，采集服务仍可能给出 0，尚未建立“不可用 / 有效零值”的状态区分。这是采集层的后续工作。
2. E/P 核心分组沿用现有的核心顺序假设，没有在所有芯片型号上验证。
3. 本次显隐选项控制展示，没有改变采集服务逐项采集的策略。
4. 设置预览沿用最近数据；面板关闭时不会为了预览恢复系统采样，界面已明确说明。
5. 历史保持 60 次采样，没有新增采样时刻轴或历史时长设置；压缩显示时显示桶内峰值而非每个原始样本。
6. 高度和间距控制的是图表区域，CPU 核心方块会随尺寸自然换行；整个模块高度仍包括标题、明细与核心网格。

## 验证

- `swift test`：57 项测试通过，包括新增 6 项测试（网格边界、空/非有限数据、历史窗口、速率刻度、迁移、局部重置）。
- Xcode Debug 应用构建通过。
- 隔离 UI 程序复用生产视图代码与固定示例数据，检查默认布局、200 pt 内存高度、仅走势、CPU/磁盘独立显示、全关提示、局部恢复默认与长面板滚动。
- 未替换用户正在运行的 MacStatus，未重置其偏好设置；UI 交互验证使用独立 bundle。

## 后续外观修正

根据实际弹窗截图调整并替换本机运行版本：

- 面板限高改为 `min(640 pt, 最小屏幕可用高度 × 75%)`，超出部分继续滚动。
- 非全宽模块由容器统一提供 16 pt 水平内边距，去除模块内部重复边距。
- 改用 `.scrollIndicators(.never)`；实机验证 `.hidden` 在“始终显示滚动条”下仍会保留侧边栏，`.never` 可消除该栏，保留滚轮/触控板滚动。
- 模块分隔线改为低对比、两端渐隐的半点细线，减少模块间距。
- 系统监控设置取消不透明的 `windowBackgroundColor` 与分组 Form，使用连续的 popover 材质和浅色分组；移除外层重复 padding。
- 设置遵循面板的浅色/深色偏好，控件统一右对齐；滑块保留数值步进，但不显示密集刻度点。
- Debug、Release 构建通过；隔离 UI 验证白底、滚动条移除，以及 640 pt 面板滚动到底部。已备份原应用与偏好后替换并启动新的 Release。
