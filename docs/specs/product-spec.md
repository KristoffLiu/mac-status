# MacStatus 产品规范 (Product Specification)

本文档阐述 MacStatus 的产品定义、核心功能与用户体验准则。MacStatus 不仅是系统自带电池图标的替代品，而是将硬件级数据以直观且优雅的形式进行可视化的极客工具。

## 1. 核心目标 (Core Objectives)

1. **实时与精准**：提供对苹果闭源电池控制逻辑的精确还原，包括目前电池的充放电细粒度功率状态、循环次数、降级评估。
2. **可视与直观**：抛弃枯燥的纯数字，使用拓扑图（桑基图）的动态流向帮助用户一秒掌握“电从哪里来，消耗到哪里”。
3. **零侵入与零耗电**: 作为系统监控类配件应用 (Accessory Application)，在后台收起时绝对不能耗费多余运算资源，杜绝电量焦虑。

## 2. 核心功能描述 (Key Features)

### 2.1 状态栏展示体验 (Menu Bar Experience)
- **多样式配置**：用户可选择只显示电池图标，或组合“百分比”、“功率数字”以及“剩余时间”。
- **充电状态反馈**：连接适配器时应立即出现插头/闪电标志。

### 2.2 下拉面板展示引擎 (Popover Panel)
- **双拓扑能量流动展示 (Dual-Topology Power Flow)**:
  - **拓扑 A（电源富余模式）**: 供电充足时，适配器的电流分两路。一路供给 **系统消耗 (System)**，一路充入 **电池 (Battery)**。
  - **拓扑 B（混合供电模式/放电模式）**: 当使用极低功率充电器，或处于未插电状态。以系统的高消耗需求为核心，汇聚 **电池放电 (Battery)** 与 **小功率电源适配器 (Adapter)** 的能量共同注入系统。
- **详尽系统状态**：以圆角的数值卡片呈现循环次数 (Cycle Count)、原厂健康度 (Max Capacity vs Design Capacity)、电流电压。

### 2.3 极致能效守恒 (Zero-Drain Behavior)
- 当用户收起 MenuBar 面板时：应用停止高频查询，停止界面绘制与动画定时器。进入极低频率仅维持基础菜单栏状态更新。
- 当用户点击展开面板时：立即以 60 FPS 唤醒渲染并恢复系统级最高精度的数据侦测。
